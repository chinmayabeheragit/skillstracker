# Skill Tracker 2026

A lightweight browser-based skill tracker for organizing learning goals, priorities, and progress.

## Features

- Track skills by category, priority, and status.
- Mark skills as pending, in progress, or done.
- Search and filter the skill list.
- View progress summaries and category completion.
- Save changes locally in the browser with `localStorage`.

## Getting Started

Open `index.html` in any modern browser.

No build step, package install, or backend server is required.

## Data Storage

Skill data is stored in your browser's local storage. Clearing site data for this page will remove saved progress.
